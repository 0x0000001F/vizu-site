The tool

Write a program, press Visualize, and watch it run.

  • Step forwards and backwards through every line, or drag the timeline.
  • The stack, the heap and every array, with pointers drawn as arrows.
  • Each condition explained in words: "Is i less than n?"
  • Mistakes stopped where they happen: past the end, NULL, used after free.
  • An editor that works like VS Code, and links that share a program.

What changed

The latest work on Vizu, newest first.

  1. 4 Oct 2026
    Inside the computer, in detailA C lab's input and output open in a window of their own: the program, the C library's buffers byte by byte, the system call with its registers, the kernel's table of calls, file descriptors and terminal driver, and the keyboard, screen and disk, with an arrow for what moves where at each stage.
  2. 4 Oct 2026
    Assembly and the CPUA new course track: how a CPU runs a program, then x86-64, ARM64 and RISC-V. Every program is assembled into real machine code and runs one instruction at a time, each through fetch, decode, execute, memory and write back, with the registers, the flags, the bytes in memory and Linux's system calls in view.
  3. 4 Oct 2026
    printf and scanf, stage by stageUnder each C lab, what the computer does for input and output: printf formats, the text waits in stdout's buffer for a newline, write takes it into the kernel, the terminal draws it. stdout can go to a file, fully buffered.
  4. 4 Oct 2026
    A flow of decisionsCourse labs draw only a function's if, while, for and switch, with the plain lines folded into one box; the way taken runs along the arrows, green out of a yes, red out of a no.
  5. 4 Oct 2026
    Memory drawn as RAM, beside the flowEvery row the run will use is drawn from the start with a short address (0x1000, 0x4000, 0x7ffc); variables fill their rows, malloc turns empty rows into a block, each p[0] = 1 writes into its box. The picture and the output keep still while you step.
  6. 4 Oct 2026
    One home for the tool and the courseThis page. The tool takes the course's look: paper and ink, with colour kept for memory (pointer blue, amber for a write, red for an error), and follows your light or dark setting. Lessons open their programs in the tool.
